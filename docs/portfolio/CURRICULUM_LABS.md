# Executable portfolio curriculum laboratories

This index connects the 32 repository-specific guides to their runnable answer keys and recorded local evidence. The 32 labs executed **209 explicit expectations** on the recorded snapshots. Each lab's grading failure path was separately checked with a deliberately wrong in-memory comparison. The missing-role engine fix also passed all seven test functions and an isolated installed-package regression.

These are synthetic software, specification or static-source checks. They do not establish learner outcomes, independent scientific reproduction, provider readiness or deployment authority. Some repositories intentionally have no application runtime. Remote CI is separate from this local evidence and remains visible on each pull request.

Run from an individual repository root:

```sh
python curriculum/lab.py --verify
```

The materials lab requires the existing NumPy dependency; the civic lab requires the existing jsonschema dependency. Other labs use the standard library and checked-in source for the exercised operations. The Grok and healthcare labs extract reviewed pure definitions without importing provider integrations.

## What changed in engineering terms

The earlier revision only described exercises. The current revision makes answers executable, compares them with committed expected results, explains the hand calculations and adds a CI job to detect source/fixture drift. It also exposed and fixed the incomplete-role overwrite in hedgeops-dti-omega. It does not claim new domain algorithms or measured learning improvement across the portfolio.

## Change and review policy

Keep edits on the existing coordinated review branches until normal repository checks and review requirements are satisfied. Do not merge around failed checks. For a changed answer, explain which mathematical assumption or contract changed and show a nearby counterexample. The canonical ResearchOs controller and existing package boundaries remain authoritative; curriculum labs do not become a second controller implementation.
