# Implementation-linked research curriculum

| Module | Study and build | Completion evidence |
|---|---|---|
| 1. Mathematical semantics | Distinguish graph connectivity, homology, dynamical stability and epistemic-state topology | A counterexample showing why these meanings cannot be substituted |
| 2. Domain computation | Run all ten topology tools on their reference and failing cases | Installed CLI bundles and bounded-scope explanation |
| 3. Contracts | Translate TruthAi dependency direction into TECT | Round-trip tests and rejection of unmapped relation types |
| 4. Evidence | Trace copied sources, signatures, freshness and revisions | A correlated-source rejection and stale-signature rejection |
| 5. Control | Exercise adjacent state transitions, challenges, reassessment and propagation | Accepted and blocked transition ledger with reasons |
| 6. Reproduction | Run the pinned Spatial/Formal/TruthAi integration and remove an edge | Changed result and reopened dependent review, without an assurance claim |
| 7. Persistence | Restart storage, race two writers and corrupt an event | Verified replay, stale-write rejection and corruption detection |
| 8. Experimental design | Freeze a four-condition protocol and define blinded truth labels | Registered task IDs, resource budgets, labels and exclusion policy |
| 9. Measurement | Collect actual observations and compute paired metrics | Reproducible report with null denominators and uncertainty stated |
| 10. Governance | Threat-model custody, access, privacy and deployment boundaries | Explicit invariants, actors and unvalidated provider conditions |
| 11. Independent review | Recruit authorized outside reviewers with domain competence | Actual reviewer consent, conflicts and signed scoped observations |
| 12. Research communication | Report failures, limits, costs and replication instructions | Claim/evidence table separating implemented, measured and proposed |

Modules are competency gates, not a promise of completion within a fixed number of weeks. External replication, reviewer availability and real data can take longer than software implementation. No module authorizes clinical deployment, autonomous trading or spending.
